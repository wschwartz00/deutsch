# Deutsch Schritt für Schritt

Personal German course (standard German, A1 → A2) for two learners: placement test, illustrated micro-lessons with recorded audio, tap-a-word lookup, stories, spaced review and progress tracking.

Live site: https://wschwartz00.github.io/deutsch/

- `index.html` – layout and styles
- `app.js` – app logic (lessons, review, placement, word lens, progress)
- `content.js` – course content (lexicon, sentences, lessons, stories, placement items)
- `art.js` – SVG illustrations
- `audio.json` + `a/` – pre-generated audio (Piper TTS, Thorsten and Kerstin voices, CC0)

Progress is stored in the browser of each device (Settings › Backup to move it).
